# Sundown Studio Clone

A modern, responsive frontend website inspired by **Sundown Studio**. This project recreates a visually engaging digital agency landing page with smooth animations, interactive sections, custom typography, and immersive UI effects.

The project was built from scratch using **HTML, CSS, and JavaScript** to practice advanced frontend development concepts, animations, and responsive web design.

## ✨ Features

### 🎨 Modern UI Design

* Recreated a premium digital agency-style landing page.
* Implemented clean layouts, typography, and visual hierarchy.
* Designed responsive sections for different screen sizes.

### 🎬 Hero Section

* Full-screen video background section.
* Animated loader experience.
* Dynamic gradient shapes and smooth visual effects.

### 🔄 Smooth Animations

* Moving text marquee animation.
* Animated background elements using CSS keyframes.
* Hover-based image preview effects.
* Smooth scrolling experience using Locomotive Scroll.

### 🖼️ Interactive Projects Section

* Dynamic image preview on hovering over project cards.
* Smooth overlay animations.
* Modern portfolio-style layout.

### 🎞️ Client Showcase Slider

* Responsive client carousel using Swiper.js.
* Supports multiple screen sizes.
* Interactive dragging experience.

### 📱 Responsive Design

* Optimized layouts for:

  * Desktop
  * Tablet
  * Mobile devices

# ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/diiksha-verma/digital-agency-website.git
```

Navigate into the project folder:

```bash
cd digital-agency-website
```

Open:

```
index.html
```

in your browser.

No additional installation is required.
